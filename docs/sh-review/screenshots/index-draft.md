## Reporting date / cut-off, buckets, wording (cross-cutting, VERIFIED)
- Cut-off shown everywhere: «المحصّل حتى 6 نوفمبر 2026 (نهاية الفترة المفتوحة = اليوم)»; period filter = issue date, default YTD 1 Jan–6 Nov 2026; Data-info popover lists cut-off, source, date basis (`ScopeFilters.jsx` DataInfo).
- Aging buckets on dashboard / Decision Room / report: «لم يحن، 1–30، 31–90، 91–180، أكثر من 180 يوماً» (5 buckets). They do **not** match the SH set (not yet due, 1–30, 31–90, 91–180, 181–365, >1 year): 181–365 and >1 year are merged, so «long outstanding» cannot be split (the standing balance is 74.3% in the >180 bucket). Uncollected list uses only 3 positions (overdue / not yet due / due date unavailable «لا شيء»).
- Missing due dates: the list shows «تاريخ الاستحقاق غير متاح — لا شيء» (zero in this data). Unidentified debtor: analysis dialog note «1 فاتورة غير مسددة: معرّف المدين ناقص». Invoice page masks the debtor ID (••••••9171).
- Wording implying accuracy: `/planning` tile «احتمالية تحقيق المستهدف 1%» (see 24); everything else carries «تقدير تجريبي – للعرض التوضيحي» / «ليس نموذجاً معتمداً». Priority is rule-based («لا درجة مركّبة») — not a probability (Decision Room, analysis page).
