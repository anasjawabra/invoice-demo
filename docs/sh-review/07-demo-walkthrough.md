## 2. What the demo must NOT claim (say it, do not let the audience infer it)

| Do not claim | Why (evidence) |
|---|---|
| A collection **probability** for any invoice or for the year | None exists: the only «probability» is a normal-tail statistic from ≤ 3 monthly points clamped to 1–99 % (`planForecast.js:30–43`); HLSD AC-10 needs calibration against a non-AI baseline; no labelled outcomes exist (00 D-8). The official decks' wording «the system processes the probability of collecting every invoice» is **not** backed by the demo (SH-A30, `06`). |
| A **validated AI forecast** or a confidence interval | The planning estimate is an explainable run-rate labelled «تقدير تجريبي – للعرض التوضيحي»; the Smart Reports trend band is «not a validated confidence interval»; the trend's own back-test error on synthetic data is ≈ 142 % (n = 6). Scenarios are not exposed. |
| **Alignment** with Dr. Muath / Abdulmajeed / the strategy team | No methodology, models, inputs, assumptions or drivers were found locally (`00 §3`) — **PENDING**. |
| **Approved** targets | Every target in the demo is `status: 'demo'`; the page shows an illustrative target of 21.59 bn while the report/chat path uses another demo target (SH-A08). |
| **Recoverability** or «uncollectible» | Not assessed anywhere («No recoverability is assessed», `NcOverview.jsx:101`); an old balance is a priority, not a write-off. |
| An **expected benefit / uplift** | None is computed in the demo; the official deck's uplift is a business-case assumption (`00 §3`). |
| **Municipality** figures as real | The Amanah → municipality hierarchy is implemented; the assignments in the generated world are demo values («قيمة تجريبية بديلة»); nothing was invented by this review. |
| **Real** debtors, contracts or payments | Synthetic only; the contract pages read a confidential Databank-derived subset and are not shown live (values blurred in every capture). |
| That the **3.89 bn and 8.32 bn** are the same number | They are two populations (this year's invoices vs everything owed to the cut-off); they bridge exactly (3.89 + 4.43 = 8.32). |
| **Conformance to the MOMAH UI/UX guideline kit** | The kit is not available locally (D-7); only the DGA foundations in the supplied workshop PDF were applied. |
| That a Shared Services **example** was supplied | None was (`00 §4` D-4). The monthly reports are real data, not dummy, and are not reproduced. |
