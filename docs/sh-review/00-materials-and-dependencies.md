**What a forecast must disclose according to the governing text (HLSD V0.6):** horizon, uncertainty, data freshness, model/rules version, data cutoff; estimate "only where labels support it"; approved fallback only "with disclosed limitations; otherwise show unavailable" (WF02-03/05, FR-010); probabilities need **calibration / Brier score** and monetary error **by horizon against an agreed non-AI baseline** (AC-10); no blanket 85% accuracy requirement (NFR-009).
