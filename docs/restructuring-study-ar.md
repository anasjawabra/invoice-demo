# دراسة إعادة هيكلة لوحات المعلومات والتقارير والتخطيط

التاريخ: 2026-10-09 · النطاق: لوحات المعلومات والتقارير والتخطيط فقط (تبقى وحدات الفواتير والتحصيل والعقود والتنفيذ كما هي).
المصادر المراجَعة: كود التطبيق (الصفحات والمسارات والمكوّنات ومنطق المؤشرات)، تقارير الإيرادات الشهرية الثلاثة (يناير–مارس 2026)، مخططات ملفات Excel، وثائق `monthly-reports-mapping-ar.md` و`revenue-sources-analysis-ar.md`، والمقارنات المعيارية الثلاث في `docs/*benchmark*`.

## 2) التكرار والغموض والنقص (تحليلي المستقل)
1. **المؤشرات الستة نفسها تُعرض أربع مرات** (التنفيذي، التحليل، الاستراتيجية، رأس التقرير الذكي) وجدول الأمانات مرتين. هذا يخفي ما يميز كل صفحة ويجعل المستخدم يسأل «أين أنظر؟».
2. **ثلاث واجهات محادثة** (المساعد، التقارير الذكية، مساعد اللوحة الاستراتيجية) بقدرات متداخلة وسياقات غير مشتركة.
3. **الصفحات تخلط الغرض:** «التنفيذي» يحوي تنبؤاً وسيناريو وتدخلاً (تخطيط) ضمن صفحة رصد؛ و«تحليل الإيرادات» يحوي أقساماً تشغيلية (سند، استثمار) وخريطة وقراراً.
4. **التقارير القياسية لا تُفتح مباشرة:** كلها خلف محادثة، والتقارير الشهرية المرفقة (صيغ ثابتة متكررة) لا مقابل ثابتاً لها.
5. **ادعاءات غير مدعومة:** «تدخل توضيحي» مخترع (سجل نتائج لم يحدث)؛ «تغطية النفقات» تعتمد اعتمادات تجريبية بحالة `unresolved` بلا إنفاق فعلي؛ لا توجد أهداف استراتيجية ولا مستهدفات معتمدة ولا ميزانية/التزام/استحقاق/صرف.
6. **التخطيط ناقص الأضلاع:** إيرادات فقط؛ لا خطة إنفاق ولا ميزانية ولا ربط بأهداف؛ لا إصدارات ولا مسؤول ولا نطاق للخطة؛ الإجراءات محلية للمتصفح.
7. **أخطاء تحميل:** «Failed to fetch» تظهر حين لا يصل الطلب لخدمة البيانات (إعادة تشغيلها/إعادة بناء البيانات)؛ عولجت بإعادة محاولة ورسائل واضحة ويبقى تعميمها على كل الصفحات الجديدة.
8. **ما يستحق الإبقاء:** الطبقة المشتركة للمؤشرات والمعادلات المعتمدة، الوحدة الواحدة المناسبة للمبالغ، مقارنة المدة المنقضية المكافئة، سجل المراجعة البشرية قبل الاعتماد، نموذج التقرير القابل للتصدير بنفس الأرقام.

## 3) البنية المقترحة ورحلات المستخدم
**منطقتان إداريتان فقط** (والباقي وحدات تشغيلية بلا تغيير):
1. **«لوحة المعلومات والتقارير»** `/insights` — ثلاث واجهات: **لوحة المعلومات** (رصد فوري بلا طلب) · **التقارير الثابتة** (صيغ قياسية تُفتح مباشرة وتُصدَّر) · **التقارير الذكية** (محادثة لتحليل مخصص).
   - يجيب: كيف الأداء الآن وأين الانحراف؟ القرار المدعوم: أين أتدخل وما التقرير الذي أرفعه؟
2. **«التخطيط المالي والاستراتيجي»** `/planning` — أهداف ومستهدفات ← خطط إيرادات ونفقات ← فعلي مقابل ميزانية/مستهدف ← توقعات وفجوات ← سيناريوهات ← مبادرات وقرارات ومتابعة.
   - يجيب: هل نحقق المستهدف؟ ما الفجوة؟ ماذا لو؟ من يتولى ماذا؟ القرار المدعوم: ما التدخلات التي نعتمدها ومن مسؤول عنها.

رحلات: (أ) المدير صباحاً → لوحة المعلومات → تعمّق في أمانة → تقرير ثابت للأمانات → تصدير. (ب) محلل → تقرير ذكي «قارن…» → متابعة «أضف تحليل الاستبعادات» → تصدير. (ج) مخطط → التخطيط → مقارنة الفعلي بالمستهدف والميزانية → سيناريو → اقتراح مبادرة → مراجع يعتمد ويسند.

## 4) خريطة القدرات (إبقاء / دمج / نقل / إزالة)
| القدرة | القرار | الوجهة |
|---|---|---|
| بطاقات المؤشرات الستة + العلاقات المالية | دمج (مرة واحدة) | لوحة المعلومات؛ والتخطيط يعرض شريطاً مضغوطاً مشتقاً منها |
| الاتجاه الشهري، التقادم، الحالات، الأمانات/البلديات/المصادر | دمج | لوحة المعلومات (موجز) + التقارير الثابتة (كاملة) |
| الخريطة، فئات الاستبعاد، الإيراد حسب المصدر سنة بسنة | نقل | لوحة المعلومات (خريطة) / تقرير الاستبعادات / تقرير المصادر |
| جسر غير المحصّل، المطابقة | نقل | تقرير «اكتمال البيانات والمطابقة» |
| التنبؤ، السيناريو، المستهدف، الفجوة والوتيرة | نقل | التخطيط |
| سجل الإجراءات والمقترحات | نقل (وتوسيع بالخطط والأهداف) | التخطيط |
| «التدخل التوضيحي» المخترع وإصدارات التنبؤ القديمة | **إزالة** | يحل محلهما سجل إجراءات بنتائج فعلية وإصدارات خطط |
| المساعد `/assistant` | دمج | التقارير الذكية (يُحوَّل المسار)؛ أسئلة الفاتورة تُجاب هناك، والإنفاذ والمصادر تُوجَّه لصفحاتها |
| مساعد التخطيط | إبقاء داخل التخطيط وبمهام تخطيطية فقط | التخطيط |
| سند، الاستثمار، التحصيل، الفواتير، العقود، الاستبعادات، الجودة، المصادر، القاموس | إبقاء | وحدات تشغيلية/مرجعية |

## 5) جاهزية البيانات
| المجال | الحالة | ما ينقص |
|---|---|---|
| الإيرادات (الفواتير، التحصيل، الاستبعاد) | **جاهزة** (تجريبية، 8 مصادر، 19 جهة) | ربط «تحصيل» ومكين الفعليين |
| المستهدفات | تجريبية غير معتمدة؛ وطنية فقط | مستهدفات معتمدة وطنية ولكل أمانة ومصدر ومنحنى شهري رسمي |
| الميزانية والالتزامات والاستحقاق والصرف | **غير موجودة فعلياً**؛ يُنشأ مجموعة اصطناعية صغيرة موسومة للعرض | بيانات نظام المالية الحكومي (اعتماد، ارتباط، استحقاق، صرف) بالأبواب والجهة والأساس المحاسبي |
| الأهداف الاستراتيجية | غير موجودة | سجل أهداف المرتبط بمؤشرات رسمية (برامج الرؤية/أداء) |
| الإجراءات والخطط | محلية للمتصفح | مخزن خادم بهوية وأدوار |
| عدد الفواتير | عينة 200–1,000 اصطناعية | لا تمثل الحجم التشغيلي |

## 6) خطوات التنفيذ (بالأولوية)
1) مقارنة معيارية ثم دراسة (هذا الملف). 2) بيانات مالية اصطناعية موسومة + حسابات التنفيذ والتغطية بأساس صريح. 3) `/insights` بواجهاته الثلاث وتحويل المسارات. 4) `/planning` بالأهداف والخطط والإصدارات والسيناريوهات الموسّعة. 5) حذف الصفحات المكررة ونقل الروابط. 6) اختبارات وتحقق ورفع الوثائق.

## 7) ما نُفِّذ (بعد الدراسة)

**بنية التنقل:** مدخلان إداريان فقط — «لوحة المعلومات والتقارير» `/insights` و«التخطيط المالي والاستراتيجي» `/planning` — يليهما الوحدات التشغيلية (الفواتير، عدم التحصيل والاستبعادات، قائمة التحصيل، العقود والتنفيذ، جودة البيانات، مصادر البيانات، قاموس المقاييس). حُوّلت المسارات: `/executive` و`/dashboard` ← لوحة المعلومات؛ `/reports` و`/smart-reports` و`/assistant` ← التقارير الذكية (مع حفظ `?q=` و`?r=`)؛ `/strategic` و`/decision-room` و`/what-if` ← التخطيط.

**الموقع الأساسي لكل قدرة (موقع واحد):**
| القدرة | موقعها الوحيد |
|---|---|
| مؤشرات الأداء الستة والعلاقات المالية، الحالة والتقادم والاتجاه والأمانات والبلديات والمصادر | لوحة المعلومات (موجز) — والتفصيل في التقرير الثابت المقابل |
| صيغ التقارير القياسية التسع (بما فيها الميزانية والمطابقة) | التقارير الثابتة |
| تقرير مخصص بالطلب وتحسينه بالمتابعة | التقارير الذكية |
| المقارنة العادلة المعدّلة بالمزيج | تقرير «أداء الأمانات والبلديات» |
| الأهداف والمستهدفات، الخطط والإصدارات، الفعلي مقابل الخطة، التوقعات والفجوات والتمويل، السيناريوهات، المبادرات والقرارات | التخطيط |
| المساعد الوصفي | التقارير الذكية؛ مساعد التخطيط يجيب بالمهام التخطيطية فقط ويحيل الباقي |

**البيانات:** مجموعة ميزانية/التزام/استحقاق/صرف **اصطناعية** صغيرة (4 أبواب × الأشهر المنقضية) في `src/data/syntheticFinance.js`، وطنية فقط، موسومة في كل شاشة وتصدير؛ لا مبالغ فعلية بعد اليوم؛ التغطية والميزان التمويلي لا يُحسبان إلا في نطاق وطني لكل المصادر وبأساس نقدي على الطرفين، وإلا «البيانات غير متاحة». عدد الفواتير ما زال عينة اصطناعية ≈ 900.

**أُزيل:** «التدخل التوضيحي» المخترع وإصدارات التنبؤ المحفوظة القديمة (`ib_rev_fc_versions` تبقى في التخزين ولا تُعرض)، خريطة المقاطعات (تكرر ترتيب الأمانات)، تبويبات تخطيط النفقات والتمويل القديمة (بلا بيانات موثوقة). **نُقل:** أقسام سند والاستثمار إلى روابط تشغيلية أسفل لوحة المعلومات.

## 8) التحقق
56 اختباراً آلياً (المعادلات والمطابقة والمرشحات والمقارنات والتصدير والسيناريوهات ومنع الازدواج والسجل والخطط والتمويل والتقارير الثابتة والتوضيح)، وفحص المتصفح: التحويلات، الواجهات الثلاث، عدم تجاوز العرض، حالات الخطأ والإعادة، وحفظ الخطط والإجراءات والمحادثات بعد إعادة التحميل.

## 9) المتبقي والتبعيات
بيانات المالية الحكومية الفعلية (اعتماد/ارتباط/استحقاق/صرف) والأساس المحاسبي؛ مستهدفات وأهداف استراتيجية معتمدة؛ مخزن خادم للخطط والإجراءات مع هوية وأدوار؛ ربط «تحصيل» ومكين؛ خدمة نموذج لغوي إن أُريدت لغة حرة. لم يُؤكَّد في المصادر السعودية المقروءة وجود طبقة «الالتزام» بين الاعتماد والصرف في التقارير العامة؛ اعتُمد التمييز الرباعي كممارسة إدارة مالية عامة دولية (راجع `ia-restructure-benchmark-ar.md`).
