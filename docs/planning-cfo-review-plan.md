# التخطيط المالي والاستراتيجي — مراجعة المدير المالي وخطة التحديث

الصفحة: `/planning` (`src/pages/PlanningArea.jsx`، `TargetsPanel.jsx`، `PlanForecast.jsx`، `EntityMap.jsx`، `planTargets.js`، `planForecast.js`).
المراجعة أُجريت على النسخة الحالية (فرع `feat/iim-v2`) بقراءة الشيفرة وتشغيل الصفحة. **لا تغيير في الشيفرة قبل اعتماد هذه الخطة.**

## 1. حكم المدير المالي في سطرين
- **المفهوم سليم**: المستهدف السنوي = مستهدف التغطية × الميزانية المبلغة (الأبواب 1–3)، والمحصّل بتاريخ الدفع، والتقدير يُعاد كل شهر.
- **التنفيذ يربكه**: أهم ما يريد أن يقرّره (المستهدفات) في **آخر** الصفحة بعد البطاقات والتقدير؛ وثلاث نسب بمقامات مختلفة بلا شرح؛ والخريطة تقرأ رقماً غير الذي عدّله؛ والجدول بلا مجموع ولا فعلي.

## 3. المبادئ التي يحكم بها المدير المالي (تُعتمد قواعد للتصميم)
1. **المستهدف أولاً**: ما يُقرَّر يظهر قبل ما يُقاس.
2. **رقم واحد لكل مفهوم**: لا تتكرر الصفحة بمجموعين أو مقامين غير معلنين.
3. **كل نسبة تُكتب بمقامها**.
4. **اللون = المقارنة بالمستهدف** لا بقيمة مطلقة.
5. **كل تعديل بأثر**: من، متى، من كم إلى كم، لماذا.
6. **عدم الادعاء**: التقدير حسابي بسيط ويقول ذلك.

## 4. الشكل الجديد للصفحة (أعلى ← أسفل)

```
┌ التخطيط المالي والاستراتيجي                                  [العام 2026 ▾] [الجهة ▾] ┐
│
│ ┌ ١. المستهدفات ─────────────────────────────────────────────────────────────────────┐
│ │ الحالة: [افتراضي — من الاعتماد]  آخر تعديل: —            [تعديل المستهدفات] [السجل] │
│ │ المستهدف السنوي للإيراد   مستهدف التغطية   مستهدف التحصيل   مستهدف الفوترة         │
│ │      11.49 مليار             35.1%              60%             19.2 مليار           │
│ │ (= التغطية × الميزانية 32.7)  (محصّل ÷ ميزانية) (محصّل ÷ صافي مفوتر)                │
│ │ ┌ جدول الجهات: الجهة │ الميزانية │ مستهدف التغطية │ المستهدف │ محصّل العام السابق ││
│ │ │ النمو المطلوب │ المحصّل حتى اليوم │ % التحقق (مقابل المخطط حتى اليوم) │ الفجوة ││
│ │ │ مستهدف التحصيل │ الفوترة    … صف الإجمالي + سطر المطابقة (قطاع الإسكان/الديوان/غير المحدد)
│ └──────────────────────────────────────────────────────────────────────────────────┘
│ ٢. أين نحن؟  بطاقات: المحصّل · المخطط حتى اليوم · الانحراف · المتبقي · المعدل الشهري المطلوب
│ ٣. التقدير: خط المستهدف/التقدير/الفعلي + سيناريوهات + أين نركز + المبررات
│ ٤. التوزيع الشهري للمستهدف (من نمط العام السابق، قابل للتعديل) — قابل للطي
│ ٥. قراءة جغرافية (ثانوية، قابلة للطي) — القسم 6
│ شريط التعريفات: التغطية · تحقق المستهدف · نسبة التحصيل (مقام كل منها)
└
```
- **4.1 «المستهدفات» في الأعلى** تعرض للجهة المختارة (أو الوزارة) الأرقام الأربعة وحالتها، وزر «تعديل المستهدفات» يفتح المحرّر في المكان نفسه (لا في أسفل الصفحة).
- **4.2 المحرّر**: جدول واحد للجهات؛ **حقل واحد قابل للتعديل لكل جهة** افتراضياً (مستهدف التغطية)، والباقي مشتق ومقروء؛ خيار «تعديل متقدم» يفتح مستهدف التحصيل أو الفوترة.
- **4.3 تعديل جماعي**: «مستهدف تغطية واحد للوزارة» (موجود) + «زيادة % على العام السابق» + «استعادة الافتراضي للكل».
- **4.4 شريط التعريفات** تحت العنوان: «نسبة التغطية = المحصّل ÷ الميزانية المبلغة · تحقق المستهدف = المحصّل ÷ المستهدف · نسبة التحصيل = المحصّل ÷ صافي المفوتر».

## 5. سلوك المستهدفات (قواعد، تُختبر آلياً)
1. **المحرّك**: `المستهدف = مستهدف التغطية × الميزانية`.
2. **الفوترة المشتقة**: `الفوترة = المستهدف ÷ مستهدف التحصيل`.
3. إن عُدِّلت الفوترة يدوياً صارت **نسبة التحصيل مشتقة** (`المستهدف ÷ الفوترة`) وتُوسَم «مشتقة من الفوترة المُدخَلة»؛ لا يُمسح أي إدخال بصمت. زر «إلغاء الإدخال اليدوي» يعيد الاشتقاق.
4. **التحقق**: التغطية ≥ 0 (تنبيه فوق 100%)، التحصيل بين 0 و100%، الفوترة ≥ المستهدف؛ تنبيه إن بعد المستهدف عن محصّل العام السابق بأكثر من ±40% (قابل للضبط).
5. **المجموع**: مجموع مستهدفات الجهات = مستهدف الوزارة دائماً؛ تعديل «الوزارة» يوزّع بنسبة المستهدفات الحالية (موجود) ويُسجَّل.
6. **التوزيع الشهري**: الافتراضي = نمط تحصيل العام السابق الفعلي (يُطبَّع إلى 100%)، ويُعاد إلى 8.33% إن لم يتوفر نمط؛ المجموع يُعرَض دائماً 100% ويُنبَّه عند إعادة التطبيع.
7. **السجل**: كل حفظ يُسجَّل (من، متى، الجهة، الحقل، قبل ← بعد، السبب). السبب إلزامي لتعديل > حد (افتراضي 5% من المستهدف) وإلا اختياري. الحالة: `افتراضي → مسوّدة → معتمد` (اعتماد لمن يملك صلاحية المراجعة؛ لا سير موافقات حقيقي في العرض ويُعلَّم ذلك).
8. **الأثر الفوري**: أي تعديل يُحدّث البطاقات والتقدير والجدول **والخريطة** في اللحظة نفسها.
9. **لا تعديل لعام بلا ميزانية**؛ تظهر رسالة بدل جدول فارغ.

## 7. التقدير والاحتمالية (تصحيح التسمية والمحتوى)

## 9. معايير القبول
- المستهدفات في أعلى الصفحة وتظهر أرقامها الأربعة وحالتها دون تمرير.
- مجموع جدول الجهات = بطاقة الوزارة = الخريطة (مع سطر المطابقة) بالتطابق المالي.
- تعديل مستهدف جهة يغيّر فوراً: الجدول والبطاقات والتقدير والخريطة؛ ويُسجَّل في السجل.
- لا إدخال يُمسح بصمت؛ المستهدف = تغطية × ميزانية في كل صف.
- لا لون أزرق ولا مستوى فوق 100% في أي خريطة أو شارة.
- لا «AI» في تسمية أي تقدير حسابي.
- اختبارات: الاشتقاق (F6)، التحقق (F12)، الجمع (F3)، السجل (F11)، لون نسبي (F4)، التوزيع الموسمي (F8).

## 10. افتراضات اعتُمدت (تغييرها سهل)
- «ما فوق 100%» = المستوى الأزرق في مقياس الألوان؛ أما القيمة الدقيقة فتبقى في البطاقة الجانبية.
- الاعتماد يتم داخل الصفحة بلا سير موافقات حقيقي (لا نظام موافقات في العرض).
- بيانات العام السابق متوفرة للمحصّل بتاريخ الدفع (تبدأ البيانات في 2025)؛ الميزانية للعام الحالي فقط.
- بقية الأرقام تبقى توضيحية اصطناعية (لا أرقام الوزارة).
